# 思源黑体原尺寸清晰版 v2.2.1

包含主游戏和 Demo 的完整汉化，不需要先安装旧补丁。适用于 Steam Build 2959430。

## 安装

1. 关闭游戏，完整解压本压缩包。
2. 双击 Install.cmd，在窗口中选择包含 desperados.exe 的游戏目录。
3. 安装器校验版本并备份原文件，随后安装主游戏、Demo 和思源黑体。
4. 从 Steam 启动，选择下方英美旗帜进入主游戏，上方英美旗帜进入 Demo。

如果已经安装本工程 v2.1 或 v2.2.0 汉化，请把保留 installation.json 和 backups 的旧“合并版汉化补丁”文件夹放在本文件夹旁边；旧主游戏包和 Demo 包也可用于导入备份。若找不到旧备份，可先用旧包 Restore.cmd 恢复，再安装新版。安装器不会覆盖无法识别的资源或丢弃旧备份。

如果 v2.2.0 原文件夹中已有 installation.json 和 backups，可以把新版解压到该文件夹并覆盖程序/资源文件，然后运行 Install.cmd；保留原有安装记录和备份。若希望单独存放旧包，请将旧清晰版文件夹命名为“思源黑体清晰版汉化补丁_v2.2.0”，与新版文件夹放在同一父目录。

## 还原

关闭游戏后运行本文件夹内 Restore.cmd，可统一还原到安装汉化前的原版资源。请保留本文件夹中的 installation.json 和 backups。升级失败会回到升级前的资源状态；因此不会留下中文文本配原版缺字字库的混合状态。

## 字体

13 套位图字库中的中文已用真实思源黑体重制，保持原有行高及字符前进宽度，保留原有拉丁字符。菜单、对白和提示采用清楚的字形及描边，选中、禁用和提示颜色仍有区分。字体覆盖主游戏和 Demo 中使用这些字库的文字。

主标题图案、教程图片、结算画面和视频内已经烧录的文字仍使用既有汉化素材；本版没有把它们当作实时字库修改。
